# Sweet Celebration Invite

Create a small, elegant, modern one-page website for a birthday party invitation.

The website should be **mobile-first**, since most guests will open it on their phones.

### Design

* Elegant and minimal aesthetic
* Background: warm white / soft beige
* Accent colors: soft pink and subtle gold
* Modern, elegant typography
* Rounded corners and subtle shadows
* Soft animations and smooth transitions
* Small festive decorative elements
* Premium and polished look, but not overly complicated
* The overall feeling should be warm, romantic, festive, and memorable

### Hero Section

At the top, create a beautiful hero section with:

**“You’re Invited to My Birthday Celebration 🎂”**

Subtitle:

**“Let’s celebrate this special day together”**

Add subtle birthday-themed decorative elements or an elegant illustration.

### Event Details

Create a beautiful information card containing:

📅 **Date:** [DATE]
🕐 **Time:** [TIME]
📍 **Location:** [VENUE]

Add a button:

**“Open in Google Maps”**

The button should open the provided Google Maps link in a new tab.

### Countdown

Add a live countdown timer until the birthday event.

Display:

**Days | Hours | Minutes | Seconds**

The countdown should update in real time.

### RSVP Section

Add a section with the title:

**“Will you join us?”**

Add two elegant buttons:

**“Yes, I’ll be there ❤️”**
**“Unfortunately, I can’t make it”**

If possible, allow the guest to enter their name and save the RSVP response using localStorage.

### Personal Message

Add a small elegant section with:

**“Your presence is the best gift we could ask for. We can’t wait to celebrate with you! ❤️”**

### Footer

At the bottom, display:

**“Can’t wait to celebrate with you!”**

### Technical Requirements

* Build it with React
* Use Tailwind CSS
* Fully responsive, especially optimized for mobile
* Smooth scrolling
* Subtle entrance animations
* Real-time countdown timer
* Clean and well-structured code
* Keep all editable information in one easy-to-find configuration section so I can quickly change:

  * Birthday person’s name
  * Date
  * Time
  * Venue
  * Google Maps URL
  * Main message
* No unnecessary pages — everything should be on a single beautiful page
* Fast loading and lightweight
* Production-ready UI
* Do not make it look like a generic template; make it feel like a real, carefully designed birthday invitation

Use tasteful spacing, elegant typography, subtle animations, and polished micro-interactions throughout the website.
